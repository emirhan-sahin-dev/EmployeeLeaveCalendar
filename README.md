# 📅 Employee Leave Calendar

Employee Leave Calendar, şirket içerisindeki **çalışan, departman ve izin süreçlerinin yönetilmesi** amacıyla geliştirilmiş web tabanlı bir personel izin ve takip uygulamasıdır.

Uygulama ile çalışanların izin kayıtları oluşturulabilir, izin süreçleri takip edilebilir ve personel izinleri **takvim görünümü** üzerinden görüntülenebilir.

## ✨ Temel Özellikler

* Departman yönetimi
* Çalışan yönetimi
* İzin türü yönetimi
* Personel izin kayıtları
* İzin talebi oluşturma
* İzin onay süreçleri
* İzinlerin takvim üzerinde görüntülenmesi
* Departmana göre filtreleme
* Çalışana göre filtreleme
* Tarih ve veri kontrolleri
* Kullanıcı yetkilendirme
* Kurumsal ve sade kullanıcı arayüzü

## 🛠️ Kullanılan Teknolojiler

* C#
* ASP.NET Core MVC
* Entity Framework Core
* Microsoft SQL Server
* HTML
* CSS
* Bootstrap
* JavaScript
* Git / GitHub

## 🏗️ Proje Yapısı

Uygulama, personel izin süreçlerinin merkezi bir sistem üzerinden yönetilebilmesi amacıyla geliştirilmiştir.

Departmanlar ve çalışanlar sistem içerisinde tanımlanarak çalışanların izin kayıtları ilgili personel ile ilişkilendirilmiştir. İzin bilgileri takvim görünümüne aktarılarak personel izinlerinin daha kolay takip edilmesi sağlanmıştır.

## 📅 Takvim ve İzin Yönetimi

Sistemde oluşturulan personel izinleri takvim üzerinde görüntülenebilmektedir.

İzin kayıtlarında tarih kontrolleri uygulanmış ve departman/çalışan bazlı filtreleme ile istenilen personelin izin durumlarının daha kolay takip edilmesi amaçlanmıştır.

## 🔐 Yetkilendirme

Uygulamada kullanıcıların sisteme giriş yapabilmesi ve yetkilerine göre ilgili işlemleri gerçekleştirebilmesi için kimlik doğrulama ve yetkilendirme yapısı kullanılmıştır.
